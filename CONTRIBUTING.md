# Contributing

Thanks for helping improve this courier tracking guide. This repository contains documentation only, so contributions are text changes to the Markdown files.

## Good contributions

- Fixing a broken or outdated link to [trackmyship.co](https://trackmyship.co/)
- Correcting or clarifying a tracking term or status meaning
- Improving troubleshooting advice with accurate, general steps
- Fixing typos, grammar or formatting

Please keep claims accurate and check them against [trackmyship.co](https://trackmyship.co/) before submitting. In particular:

- The site tracks courier tracking numbers (AWB, consignment, waybill, Speed Post) only, not mobile numbers, email addresses, LR numbers or order IDs.
- There is no public Track My Ship API. Don't add endpoints, code samples or integrations.
- Don't describe any courier as a partner of Track My Ship, and don't add courier logos.

## How to contribute

1. Fork the repository.
2. Create a branch, for example `fix-status-meanings`.
3. Make a focused change. Check that links work and headings render correctly.
4. Open a pull request that explains what you changed and why.

## Reporting problems

Open an issue to report an error in the documentation. For problems with the website itself, email info@trackmyship.co. For a problem with a specific parcel, contact the courier or the sender, because they can act on the shipment.

## Privacy

This is a public repository. Never include:

- Real tracking numbers for private shipments
- Names, addresses, phone numbers or email addresses
- Screenshots of receipts, labels or tracking results showing personal details
- Passwords, API keys, tokens or other credentials

Use clearly made-up example numbers when illustrating a format.

Contributions must be your own wording. Don't copy text from courier websites or other sources.
